# 专业量化股票分析系统（含Word报告下载）

## 项目概述
这是一个集成化的股票分析AI智能体，通过Web界面分析指定股票，使用AI模型生成分析报告，并生成可下载的Word文档。该系统集成了数据获取、技术分析、基本面分析、资金流向分析以及AI报告生成等功能。

## 功能特性
- 实时股票数据获取
- 专业技术指标分析（移动平均线、RSI、MACD、布林带等）
- 基本面数据分析
- 资金流向分析
- AI驱动的量化分析报告
- 可视化图表展示
- Word报告一键下载
- 灵活的时间段分析

## 技术架构
- **前端界面**: Gradio Web框架
- **数据获取**: AkShare财经数据接口
- **AI分析**: 通义千问API
- **文档生成**: python-docx库
- **图表绘制**: matplotlib库
- **数据处理**: pandas和numpy库

## 依赖安装
```bash
pip install akshare gradio python-docx matplotlib pandas numpy requests
```

## 配置要求
1. 需要有效的通义千问API密钥
2. 网络连接（用于数据获取和API调用）
3. Python 3.7+ 环境

## 使用方法
1. 安装所有依赖库
2. 配置有效的QWEN_API_KEY
3. 运行 `python app.py`
4. 访问 Web 界面：http://localhost:7868
5. 输入股票代码，选择分析时间段，输入分析问题
6. 点击"开始专业分析"按钮
7. 分析完成后，点击"Word报告下载"按钮下载完整报告

## 界面说明
- **股票代码**: 输入要分析的股票代码（如：000001、600519等）
- **日期选择模式**: 
  - 指定日期：自定义开始和结束日期
  - 最近天数：分析最近N天的数据
  - 从某天开始持续：从指定日期开始持续N天
- **分析问题**: 输入您希望AI分析的具体问题
- **量化分析报告**: AI生成的详细分析报告
- **价格趋势图**: 股票价格走势及移动平均线
- **成交量图**: 成交量变化趋势
- **技术指标图**: RSI等技术指标
- **原始数据摘要**: 获取的原始数据JSON格式
- **Word报告下载**: 生成的Word报告文件下载

## 分析模块
1. **行情摘要**: 最新价格、涨跌幅、成交量等
2. **关键指标看板**: PE、PB、技术指标等
3. **技术分析**: 趋势判断、动量分析、MACD等
4. **基本面与估值**: 营收、净利润、ROE等
5. **资金流向**: 主力资金、大单流向等
6. **综合结论**: 操作建议和风险提示

## API配置
在代码中找到 `QWEN_API_KEY` 变量并替换为您的实际API密钥：
```python
QWEN_API_KEY = "your_actual_api_key_here"  # 请替换为你的API密钥
```

## 错误处理
- 如果网络请求失败，系统会自动使用模拟数据
- 如果API调用失败，会返回原始数据摘要
- 如果图表生成失败，会跳过该图表

## 技术指标说明
- **移动平均线(MA)**: MA5、MA10、MA20、MA60
- **相对强弱指数(RSI)**: 14日RSI及状态
- **MACD指标**: DIF、DEA、柱状体及信号
- **布林带**: 上轨、中轨、下轨及位置
- **支撑阻力位**: 计算出的支撑位和阻力位
