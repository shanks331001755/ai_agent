# AI Agent 开发规则和注意事项

1.写这个项目之前先确定这个结构，你给出方案我来挑选简易程度
2.我挑选好了后你先完整地确定.md文件(如果是简单的一个单文件系统就没必要确认.md文件；如果是使用 Gradio 或 Streamlit 这类专为AI设计的库，用极简的Python代码生成一个带有输入框、按钮、图表展示区的Web页面可以看情况写.md文件，简单的就不写，复杂的就写；如果是 前后端分离Web服务或者是分布式系统就一定要写.md文件)
3.根据这个.md文件来写代码
4.写代码之前把要用到的库和什么什么之类的在命令行下载号=好并验证
5.写代码之前给你几个需要注意的几个点
5.1如果是AI大模型的API调用失败了，记得去测试是这个API没用了还是余额不足，把结果发给我
5.2如果是数据获取的API调用失败了，看看是限制访问频率还是要收费我的余额不足，数据获取方面的API我一般不会去买，你可以给我推荐稳定好用的和适用与什么场景比如完成学习任务用什么数据源，企业级开发用什么数据源等等，这些你都可以询问我
5.4简单的web页面好像有免费的模板使用比如AI使用的库Gradio什么的，以后我做其他简单的集成应用你可以给我推荐还有什么好的现成的预配制布局
5.3做复杂点的前后端分离有现成的Vue预配制布局就用现成的，省的写前端了，直接写后端与其对接就可以了
6.写代码时要注意的点：
6.1生成的图如果上下波动大的话，我在网页是上要用鼠标滑动大半天才可以到底部，对于各种折线图，柱状图以及其他的都给我设置固定大小
6.2前端弄出来的按钮一定要是有用的，点击没反应的就不要设置了
6.3对于分析股票方面，首先对日期处理格式要到位要不然代码运行报错，然后就是我分析股票我可以选择日期，我来选择从某天开始为期多少多少天分析这段时间的股票，默认就是分析最近时间段的股票
6.4功能不要太单调了股票分析系统不止是分析股票还要有其他功能，比如对比啊，预测啊，查询啊等等功能
6.5写的测试文件记得去新建一个测试文件夹把测试的代码脚本都放这个文件夹里面
6.6当你要在命令行运行一段python代码时，建议你建立一个文件然后执行这个文件，尽量不要直接把代码写在终端运行
6.7问ai 去得到提示词然后再发给ai
6.8修改代码过长时，请记得分段处理
6.9能运行并不代表功能没问题不要一运行成功你就结束了
6.10你的终端命令不要再用&&命令了
